# W-002E-R2 — Fiducial Physical Geometry Metrology

상태: `PASS_PHYSICAL_GEOMETRY_METROLOGY / CLOSED`

설치된 검은 사각형의 바깥 변을 그대로 기록했다. PnP는 다시 하지 않았고, 등록에 쓰는 크기는 60 mm 명목값 그대로다.

| ID | 가로 mm | 세로 mm |
| --- | ---: | ---: |
| 0 | 59 | 59 |
| 1 | 60 | 60 |
| 2 | 59 | 59 |
| 3 | 59 | 59 |

여덟 값의 산술평균은 59.25 mm다. 이 평균을 새 marker size로 쓰지 않는다. 59 mm가 여섯 번, 60 mm가 두 번이다. ID1만 60 mm인 이유가 인쇄 차이인지 읽기 차이인지는 구분하지 않는다. `PRINT_GEOMETRY_PATTERN = INCONCLUSIVE`.

W-002E-R1에서 58 mm 쪽 시뮬레이션이 재투영을 줄였다는 사실로 실제 크기가 58 mm라고 하지 않는다. 이번 측정만으로 재투영 실패 원인을 인쇄 축척으로 확정하지 않는다.

승인된 `T_camera_workboard`는 없다. 마커, 카메라, 로봇, 작업판은 움직이지 않았다. W-002E와 W-002E-R1 기록은 바꾸지 않았다.
