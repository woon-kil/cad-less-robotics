# Sensor and workcell roles

## Gemini 335L

고정된 Eye-to-Hand 전역 인식 센서다.

역할은 작업면 관찰, RGB-D 획득, 점군 생성, 형상 추출, 이후의 CAD/스캔 정합, 공정 경로의 명목 생성이다.

이 revision에서 카메라를 옮기지 않는다. P-003과 P-004 이후의 설치를 유지한다.

## DOFBOT

로봇 실행 플랫폼이다. 이 단계에서는 조인트 명령, 홈, MoveIt `execute`를 보내지 않는다. 베이스도 옮기지 않는다.

## Checkerboard

보정과 측정 검증용 타깃이다. 로봇이 수행할 작업이 아니다.

체크보드를 로봇 작업 영역 밖까지 보내기 위해 작업면을 늘리거나 카메라 받침을 치우지 않는다.
