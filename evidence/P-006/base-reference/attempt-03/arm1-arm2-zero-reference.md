# Arm1 각 0에서의 XY

P-002와 같은 URDF다. ballbot `906da9f9120c056dd0c8766fe1a72e72a086061c`, `DOFBOT_Pro-V24.urdf`.

`A_AXIS`와 +Z 판정은 바꾸지 않는다.

## 관절 원점

`Arm1_Joint`는 `base_link`에서 `Arm1_Link`로 간다. origin xyz `0 0 0.0895`, rpy `0 0 0`, axis `0 0 1`.

`Arm2_Joint`는 `Arm1_Link`에서 `Arm2_Link`로 간다. origin xyz `0 0 0.0329999999999998`, rpy `0 0 0`, axis `1 0 0`.

Arm1 각이 0이면 Arm2 원점의 XY 성분은 `(0, 0)`이다. `base_link`에서의 높이는 0.0895 + 0.0329999999999998 = 0.1224999999999998 m이고, X와 Y는 0이다.

이 원점은 +X도 +Y도 가리키지 않는다. 병진이 축 방향에 없다.

## 모델이 정하는 방향

방향을 주는 것은 원점 병진이 아니라 `Arm2_Joint` axis `1 0 0`이다.

Arm1 각 0에서 어깨 회전축은 `base_link` +X와 같다. +Z는 이미 확인된 `A_AXIS`다. +Y는 그 둘에 대한 오른손 축이다. +Y = +Z × +X.

`Arm2_Link.STL`은 이 결론과 맞다. visual origin은 `0 0 0`이고 scale 요소는 없다. 꼭짓점 범위는 X -0.023800000548362732 ~ 0.023800000548362732 m, Y -0.017600009217858315 ~ 0.011462035588920116 m, Z -0.013650004751980305 ~ 0.09335000067949295 m이다. 꼭짓점의 67.13%가 Z > 0.02 m다. X의 양쪽은 거의 같다.

zero configuration에서 어깨 링크가 뻗는 방향은 작업판을 가로지르는 +X나 +Y가 아니다. `A_AXIS`와 같은 +Z다. yaw=0의 수평 기준은 팔이 가리키는 쪽이 아니라 어깨 힌지 축이다.

Y 범위가 -Y로 약 6 mm 더 길다. 중심의 Y는 -7.06112511930687e-05 m라 이 차이를 팔이 뻗는 방향으로 쓰지 않는다.
