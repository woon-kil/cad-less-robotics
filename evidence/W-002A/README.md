# W-002A

`PASS_FIDUCIAL_OBSERVABILITY / CLOSED`

고정된 카메라, 로봇, 작업판에서 `DICT_4X4_50` ID 0, 검은 사각형 60 mm 마커를 아래 6곳에 두고 RGB 검출과 중심 depth를 확인했다.

```text
(150,70) (300,70) (500,70)
(150,330) (300,330) (500,330)
```

6곳 모두 검출되었고, 마커 전체가 보였고, 중심 depth가 유효했다. 측정 중 카메라, 로봇, 작업판은 움직이지 않았다. 측정된 위치에서 로봇, 카메라 마운트, 다른 물체에 가려지지 않았고 물리 간섭도 없었다.

이 합격은 그 6개 이산 위치에서만 성립한다. `X=150~500 mm`, `Y=70~330 mm` 직사각형 안의 연속 가시성을 뜻하지 않는다. 작업판 좌표 정합, `camera↔workboard` 변환, 로봇 도달 범위, ProcessSurfaceScope, P-009 해결을 뜻하지 않는다.

ID 0, 1, 2, 3의 설치 좌표는 정하지 않았다. 마커를 작업판에 고정하지 않았다. 정합은 수행하지 않았다. P-009-R1과 P-010은 열지 않았다.

`(150,70)`의 중심 픽셀, 마커 픽셀 크기, 깊이는 검수에서 확인된 것으로 적혀 있고, 종료 표에 숫자가 다시 적히지 않았다. 나머지 5곳의 숫자는 각 위치의 현재 프레임 측정이다. `(150,0)` 검출 실패는 `evidence/W-002A-D1/`에 남아 있으며 이 6점 조사에 넣지 않는다.
