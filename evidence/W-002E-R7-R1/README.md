# W-002E-R7-R1 — 물리 복구 완료

상태: `PASS_PHYSICAL_RECOVERY_COMPLETION / CLOSED`

W-002E-R7의 `BLOCKED_ID2_CENTER_UNMEASURED_AND_SIDE_VIEW_ABSENT`는 고치지 않았다. 이 Gate는 그 blocker를 뒤의 기록으로 해소한 것이다. W-002E-R6도 그대로다.

## 실측

줄자는 `1_MM_GRADUATED_TAPE_MEASURE`다. 1 mm는 최소 눈금이고, ±1 mm 정확도가 아니다.

과거 중심 `(500, 336)`에서 읽은 중심은 `(450, 336)`이다. 목표와 숫자가 같다. 목표를 측정 없이 복사한 것은 아니다. X는 과거보다 -50 mm, Y는 0이다. 목표와의 차이는 X 0 mm, Y 0 mm다.

같은 ID2 시트를 옮겼다. 다시 인쇄하지 않았다.

이후 registration의 ID2 중심은 이 실측 `(450, 336)`이다. W-002D-R1의 `(500, 336)`을 다음 등록에 쓰지 않는다.

## 측면

사용자가 재설치 후 측면에서 검은 영역이 나무에 붙어 있고 틈이 없다고 확인했다. 이것은 눈에 보이는 설치 평탄이다. 정밀 평면도나 mm, µm 정확도로 확대하지 않는다.

그 측면 원본 파일은 이 작업 공간에 없었다. R6의 들뜬 상태 사진을 재설치 후 사진으로 넣지 않았다.

흡착판 비접촉과 ID 0~3 가시는 W-002E-R7에 있던 기록을 유지한다.

## 이 합격이 아닌 것

등록은 실행하지 않았다. 검증된 `T_camera_workboard`는 없다. W-002E의 원인은 아직 확정되지 않았다. ID2가 재투영 실패나 -2.34 mm의 원인이라는 것도 확정하지 않았다.
