# W-002C — Fiducial layout physical validation

상태: `BLOCKED_PRINT_METROLOGY / CLOSED`

ID 0, 1, 2, 3이 한 RGB 프레임에서 함께 검출되었다. 검출 파라미터는 기본값이고 PnP는 하지 않았다. 마커는 테이프로 고정하지 않았다.

출력물의 검은 사각형, quiet zone, 종이 두께, 테이프 두께는 자로 재지 않았다. 그 칸을 추정으로 채우지 않았다. 그래서 설치 가능 검증은 합격이 아니다.

## 동시 검출

| ID | 중심 px | 픽셀 크기 | 전체 가시 | 영상에서 흰 테두리 |
| --- | --- | --- | --- | --- |
| 0 | (454.75, 651.50) | 79.86 × 65.30 | YES | YES |
| 1 | (750.00, 432.00) | 44.83 × 51.41 | YES | YES |
| 2 | (599.00, 304.25) | 40.56 × 33.93 | YES | YES |
| 3 | (333.75, 450.50) | 62.18 × 40.59 | YES | YES |

W-002B의 registration 최소 3개는 이 검증의 합격 조건이 아니다. 이번 프레임은 4/4다.

네 장 모두 프레임 안에 있고 로봇, 마운트, 클램프, 작업물에 가려지지 않았다. ID 2와 로봇 베이스 사이에는 나무면이 보인다. 신발은 작업판 밖에 있다.

## 원점

카메라 스탠드 쪽 짧은 변과 가까운 긴 변의 교점은 영상에 보인다. 클램프와 카메라 마운트는 그 모서리 앞쪽에 있고 모서리 점을 덮지 않는다. 이 게이트에서 그 모서리에 자를 반복해서 대지는 않았다.

## 맨 나무 영역

네 마커 안쪽, 로봇 베이스에 닿지 않은 나무면을 하나 표시해 두었다. 이 프레임의 픽셀 범위는 u 480–700, v 430–560이다. 평면 검증은 실행하지 않았다.

## 하지 않은 일

영구 부착, registration, threshold 변경, WorkpieceInstance 선택, P-009-R1, P-010은 없다. W-002B 계약 파일은 바꾸지 않았다.
