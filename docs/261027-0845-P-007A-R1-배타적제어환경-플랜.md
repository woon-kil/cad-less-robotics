## 차단 요소 (Do 진입 전 해소 필요)

1. **SSH 접근**. 이 Mac에서 `ssh -o BatchMode=yes jetson@192.168.0.94`는 `Permission denied (publickey,password)`다. `known_hosts`에 192.168.0.94 항목 3개가 있어 과거 접속 이력은 있으나 현재 키 인증이 되지 않는다. 사용자가 공개키를 설치하거나 접속 방법을 알려주기 전에는 R1 실행 불가. 자격증명 탐색은 하지 않는다.
2. **sudo 가능성**. `jupyterlab.service`는 system unit이므로 중지에 sudo가 필요하다. `sudo -n true`로 비밀번호 없는 sudo 여부를 먼저 확인하고, 안 되면 R1-09는 사용자 실행 단계로 분리한다.

## 접근 방법

- A. SSH로 명령을 한 줄씩 보낸다. 장점: 단계마다 판단 가능. 단점: 운영 호스트 다단계 변경이 기록 없이 흩어지고 멱등·롤백이 없다.
- B. `scripts/p007a_r1_snapshot.sh`(읽기 전용) · `p007a_r1_isolate.sh`(격리+회귀) · `p007a_r1_restore.sh`(원복)로 패키징하고, 각 스크립트가 원본 백업·해시·검증을 스스로 수행한다. 장점: 운영 호스트 변경이 멱등·가역이고 증거가 파일로 남는다. 단점: 스크립트 3개가 늘어난다.
- C. Jetson 안에 스크립트를 복사해 로컬 실행. 장점: SSH 왕복이 적다. 단점: 로봇 호스트에 파일을 남긴다(벤더 환경 변경 최소화 원칙과 충돌).

선택: **B**. 글로벌 규칙(운영 호스트 작업은 길이 무관 스크립트 강제, 7요소: shebang+`set -euo pipefail`, 사용법 주석, 사전 검증, 백업, 멱등성, 검증 단계, 롤백 명령)을 따른다. 스크립트는 Mac에서 실행하고 SSH로만 원격에 작용한다. `restore`는 `isolate`보다 **먼저** 작성하고 `--dry-run`으로 확인한다.

## 금지 명령 (게이트 전체)

- `i2cdetect`, `i2cget`, `i2cset`, `i2ctransfer` — 버스 스캔·probe는 컨트롤러에 실제 전송을 일으킨다. 다른 I2C 어댑터 조사는 `/sys/class/i2c-dev`, `/sys/bus/i2c/devices`, dtb/mux 정보 같은 **정적 읽기만** 쓴다.
- 게이트 진행 중 **재부팅·재로그인·세션 재시작·전원 재투입 금지**. 전원 재투입은 호스트 autostart 격리와 무관하게 컨트롤러·벤더 초기 자세 동작을 일으킬 수 있다(`startup_inventory.json`의 `power_on_vendor_doc`).
- SIGINT(`Ctrl-C`, `kill -2`) 금지. KeyboardInterrupt가 cleanup 코드를 돌려 `write6`를 낼 수 있다.
- 프로세스 그룹·세션 일괄 종료(`kill -- -PGID`, `pkill -f python3`), `gnome-terminal-server` 종료 금지. 지정 PID만 다룬다.

servo position·gripper 명령, homing·reset·calibration, torque 변경, MoveIt, joint jog, `arm_driver.py` 실행, P-007B, P-006D, `T_base_camera`, 로봇·Gemini·LED 이동, 전원 차단 시험, i2c 버스 probe, CONDITIONAL PASS.

## 판정 규칙

- PASS: uncontrolled servo writer 0 + servo-capable network entrypoint 0 + autostart isolation 확인(정적) + 60초 respawn 0 + 읽기 600/600 error 0 + 격리 전후 각도 6개 동일 + 운영자 무동작 확인 + 물리 전원 경로 확인 + clearance 확인. 이때만 `P-007B MAY BE DESIGNED`(실행 허가 아님).
- BLOCKED: uncontrolled writer 잔존, autostart·서비스 재생성, UNKNOWN writer 잔존, 전원 접근 미확인, clearance 미확인, 읽기 회귀 실패, SSH·sudo 미해소 중 하나.
- FAIL: 격리 중 의도하지 않은 motion 또는 controller state mutation(각도 변화). 즉시 STOP.
- CONDITIONAL PASS는 쓰지 않는다.
